## 📌 About the Project

This project is a combination of a traditional vintage wall clock and a modern digital clock. It features a classic analog clock design with Roman numerals, elegant clock hands, a wooden-style frame, and a swinging pendulum.

Along with the analog clock, it displays real-time digital time, date, and day.

The project is developed using HTML, CSS, and JavaScript.

## ✨ Features

- 🕰️ Vintage-style analog wall clock
- 🪵 Classic wooden clock design
- 🔢 Roman numeral clock numbers
- ⏱️ Real-time hour, minute, and second hands
- 🔔 Animated swinging pendulum
- 💻 Digital clock display
- 📅 Live date and day display
- 🔄 Automatically updates every second
- 🎨 Custom vintage-inspired user interface
- 📱 Responsive design

## 🧠 How It Works

1. JavaScript retrieves the current system time.
2. The analog clock hands rotate according to hours, minutes, and seconds.
3. The digital clock displays the current time.
4. The date and day are updated automatically.
5. CSS animations create the swinging pendulum effect.
